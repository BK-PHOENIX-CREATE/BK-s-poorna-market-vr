# Market VR — 9th Semester Architectural Design

Interactive market architecture presentation for desktop walkthroughs and WebXR-compatible VR headsets.

## Current phase
- React + Vite + Three.js starter prepared separately
- Demonstration model ready to replace with the actual SketchUp model
- Production build and headset testing pending
- SketchUp `.skp` model must be exported/converted to optimized `.glb`

## Run locally
```bash
npm install
npm run dev
```

## Deployment
Once website source is committed, import this GitHub repository into Vercel using the Vite framework, build command `npm run build`, and output directory `dist`.

## Notes
The website uses the browser WebXR API. Immersive VR requires a supported headset/browser and secure HTTPS origin. The demo design and text are placeholders, not the student's submitted architectural model.
